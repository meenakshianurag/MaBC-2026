3. ESTIMATE

All three cohorts use platform = "illumina", which returns the stromal, immune and combined scores only. ESTIMATE’s TumorPurity formula ("affymetrix") was fitted on Affymetrix intensities and is not valid for the Callari two-color log2 ratios, so no ESTIMATE purity is used. The scores are rank-based (ssGSEA) and are compared between sexes within each cohort, not across cohorts.

run_estimate <- function(expr) {
  merged <- filterCommonGenes(expr, id = "GeneSymbol")
  sc <- as.data.frame(estimateScore(merged, platform = "illumina"))
  out <- as.data.table(t(sc))
  stopifnot(nrow(out) == ncol(expr), !anyNA(out))
  out[, sample := colnames(expr)]
  setcolorder(out, "sample")[]
}

6. Differential expression, unadjusted vs adjusted

Both runs use limma on the same samples (those with complete covariates), so the only difference between unadjusted and adjusted is the covariates. trend = TRUE is used for log-CPM input; the Callari microarray matrix uses the default.

Covariates: TCGA, CPE purity + immune score; Callari, ESTIMATE score (purity proxy) + immune score. With only 12 male TCGA cases the model is deliberately limited to two covariates — adding age and stage would leave too few residual degrees of freedom.

## covars: used in the model; keep_by: defines the sample set (same for both runs)
run_limma <- function(expr, meta, covars = character(0), keep_by, trend = TRUE) {
  stopifnot(all(c(covars, keep_by) %in% names(meta)))   # never drop a covariate silently
  meta <- copy(meta)[, sex := factor(sex, levels = c("female", "male"))]

  keep <- complete.cases(meta[, c("sex", keep_by), with = FALSE])
  if (sum(!keep)) message("  dropping ", sum(!keep), " samples with missing covariates (",
                          sum(!keep & meta$sex == "male"), " male)")

  form <- as.formula(paste("~ sex",
            if (length(covars)) paste("+", paste(covars, collapse = " + ")) else ""))
  design <- model.matrix(form, data = droplevels(meta[keep]))

  fit <- eBayes(lmFit(expr[, keep, drop = FALSE], design), trend = trend)
  tt <- as.data.table(topTable(fit, coef = "sexmale", number = Inf),
                      keep.rownames = "gene")
  tt[, signed_logP := -log10(P.Value) * sign(logFC)][order(-signed_logP)]
}

cov_tcga <- c("purity", "ImmuneScore")
cov_call <- c("ESTIMATEScore", "ImmuneScore")

8. Do the tumor-associated modules survive adjustment?

Two points govern how this is judged. First, adjusted and unadjusted results are both produced with limma, so they are directly comparable to each other — but limma with 12 male TCGA cases is markedly less powerful than the Wilcoxon-based ranking used in 05, and few TCGA modules reach FDR < 0.05 under either model. TCGA is therefore used for direction and effect size, not for significance. Second, the Callari cohort (37 vs 53) is adequately powered and carries the significance test.

9a. Both tumor cohorts

Each point is one tumor-associated module from 05, that is, significant in both TCGA and Callari and not significant in GTEx normal breast. Color indicates the direction of that classification. Panels are annotated with the correlation between adjusted and unadjusted NES and the median absolute shift; points on the diagonal are unaffected by adjustment. GTEx is not shown because purity adjustment does not apply to normal tissue.

## long format: one row per module x cohort, carrying that cohort's own
## significance calls for use in panel 9b
nes_long <- rbindlist(lapply(c("Callari", "TCGA"), function(co)
  data.table(cohort    = co,
             pathway   = w$pathway,
             direction = w$direction,
             before    = w[[paste0("NES_",  co, "_unadjusted")]],
             after     = w[[paste0("NES_",  co, "_adjusted")]],
             p_before  = w[[paste0("padj_", co, "_unadjusted")]],
             p_after   = w[[paste0("padj_", co, "_adjusted")]])))
nes_long <- nes_long[complete.cases(before, after)]
nes_long[, cohort := factor(cohort, c("Callari", "TCGA"))]
